================================================================================

    *** HOLISTIC SEO (SEO HOLISTIK / OPTIMASI PENCARIAN MENYELURUH) ***

Setiap keputusan teknis, konten, dan desain di proyek ukmipolmed.xo.je WAJIB
diambil dengan prinsip HOLISTIC SEO. Bukan sekadar SEO teknis (schema, url,
alt text), tetapi menyeluruh yang mencakup 4 pilar:

    1. TECHNICAL SEO  -> schema JSON-LD, canonical, hreflang, url bersih,
                         sitemap/robots, performa (Core Web Vitals), keamanan.
    2. CONTENT SEO    -> long tail, content silo, TOFU/MOFU/BOFU, AEO, GEO.
    3. AUTHORITY SEO  -> E-E-A-T (Experience, Expertise, Authoritativeness,
                         Trustworthiness), sameAs, konsistensi brand.
    4. UX / SXO       -> Core Web Vitals, mobile-first, alt text, keterbacaan,
                         pengalaman pengguna yang baik.

Prinsip turunan yang tidak boleh dilanggar:
  - Jangan pernah menambah "thin content" atau konten yang membunuh SEO
    (duplikat, keyword stuffing, konten tanpa nilai) demi mengisi halaman.
  - Setiap perubahan harus menjaga keseimbangan 4 pilar di atas.
  - AEO & GEO adalah bagian dari Holistic SEO (optimasi era AI), bukan terpisah.

Status prinsip ini: PERMANEN — tidak boleh dihapus/direset oleh perubahan lain.

Website ini adalah situs UKM (Unit Kegiatan Mahasiswa Islam Politeknik Negeri

BAGIAN 3 — KAMUS KONSEP SEO (ILMU & TRIK)
================================================================================

--------------------------------------------------------------------------------
3.1 AEO — Answer Engine Optimization
--------------------------------------------------------------------------------
Optimasi agar konten menjadi JAWABAN LANGSUNG di mesin jawaban (Google AI
Overviews/SGE, ChatGPT Search, Perplexity, Bing Copilot).

Trik praktis:
  - 40-60 kata pertama paragraf harus langsung menjawab pertanyaan.
  - Gunakan heading berbentuk pertanyaan natural ("Apa itu UKMI Polmed?").
  - Pasang schema FAQPage & QAPage.
  - Tulis ringkasan padat di awal, detail menyusul.

Status web ini: faq.php sudah cocok (FAQPage ada). Perlu tambah schema QAPage
dan struktur tanya-jawab di konten blog.

--------------------------------------------------------------------------------
3.2 GEO — Generative Engine Optimization
--------------------------------------------------------------------------------
Sepaket dengan AEO, fokus pada: dikutip (citation) oleh model AI.
  - Brand mention konsisten ("UKMI Polmed").
  - Sediakan data/angka orisinal (statistik kegiatan, jumlah anggota, tahun).
  - Struktur HTML semantik & kutipan jelas memud让kan model mengutip sumber.

Perbedaan singkat: AEO = jawaban langsung di SERP; GEO = direferensikan AI.

--------------------------------------------------------------------------------
3.3 Long Tail Keyword
--------------------------------------------------------------------------------
Keyword spesifik, volume kecil, konversi tinggi.
  Short tail        -> Long tail
  "UKMI"            -> "UKMI Politeknik Negeri Medan kegiatan 2026"
  "pendaftaran"     -> "cara daftar UKMI Polmed online 2026"
  "agenda"          -> "agenda kegiatan mahasiswa Polmed November 2026"

Sumber long tail di web ini: judul post blog spesifik, pertanyaan faq.php,
nama agenda + tahun. Tips: riset keyword gratis (Google autocomplete, People
Also Ask, Search Console) sebelum menulis konten.

--------------------------------------------------------------------------------
3.4 Schema Website (JSON-LD / Structured Data)
--------------------------------------------------------------------------------
Struktur data di <head> agar Google paham konteks konten -> memperoleh rich
snippet. Format: <script type="application/ld+json">.

Jenis schema relevan untuk web ini:
  - Organization      : identitas UKMI (nama, logo, alamat, sameAs sosmed)
  - WebSite           : + SearchAction (mesin pencari internal)
  - WebSite/Breadcrumb: navigasi
  - FAQPage / QAPage  : faq.php
  - BlogPosting       : tiap post blog.php
  - Event             : agenda kegiatan (tanggal, lokasi, penyelenggara)
  - DiscussionForumPosting : komentar di blog

Status web ini:
  [BAIK]  index.php: FAQPage, WebSite, Organization, BreadcrumbList
  [BAIK]  blog.php : BlogPosting + BreadcrumbList
  [BAIK]  faq.php  : FAQPage, BreadcrumbList, WebSite
  [KURANG] Belum ada Event, sameAs, SearchAction, DiscussionForumPosting

Tips: validasi dengan Google Rich Results Test & Schema Markup Validator.

--------------------------------------------------------------------------------
3.5 E-E-A-T
--------------------------------------------------------------------------------
Experience, Expertise, Authoritativeness, Trustworthiness — sinyal kualitas
yang menilai kredibilitas konten (penting untuk topik YMYL).

  - Experience       : foto kegiatan nyata, cerita alumni, dokumentasi.
  - Expertise        : tulisan oleh pengurus/mentor, cantumkan penulis.
  - Authoritativeness: diakui kampus, aktif, dirujuk pihak lain.
  - Trustworthiness  : kontak valid, HTTPS, info jelas, tanggal update.

Status web ini:
  [BAIK]      HTTPS aktif, halaman info & status tersedia.
  [PERLU]     Author byline tiap post, halaman Tentang/Sejarah/Visi-Misi,
              testimoni alumni, tanggal update, halaman kontak resmi.

--------------------------------------------------------------------------------
3.6 Content Silo
--------------------------------------------------------------------------------
Arsitektur konten berbentuk silo (kerucut): topik utama di puncak, subtopik
mengumpul di bawah, saling terhubung via internal linking.

Contoh struktur untuk web ini:

                 UKMI POLMED (beranda)
                /          |           \
         Kegiatan       Organisasi     Informasi
         /     \        /       \      /      \
     Agenda   Blog  Pengurus  Sejarah  FAQ    Info
     /  \      \
  2025  2026  Tips

Aturan:
  - Tiap silo hanya saling link di dalam silonya (hindari lompat silo).
  - Anchor text mengandung keyword.
  - URL bersih & berstruktur.

Status: [BELUM] struktur silo & internal linking antar silo belum diterapkan.

--------------------------------------------------------------------------------
3.7 TOFU / MOFU / BOFU (Content Marketing Funnel)
--------------------------------------------------------------------------------
Perjalanan pengunjung dari "belum kenal" hingga "siap bergabung".

  Tahap          Fungsi                Contoh konten di web ini
  TOFU (Top)     Awareness             Artikel blog "Mengenal UKMI Polmed"
  MOFU (Middle)  Consideration         FAQ, profil pengurus, galeri, testimoni
  BOFU (Bottom)  Decision/Konversi     Form pendaftaran, link daftar, kontak

TOFU tarik trafik -> MOFU bangun minat -> BOFU konversi jadi anggota baru.

Status: [BELUM] pemetaan funnel belum dibuat; form pendaftaran sudah ada
(registrationDefaults -> Google Form) sebagai aset BOFU.

--------------------------------------------------------------------------------
3.8 Alt Text & Anchor Text
--------------------------------------------------------------------------------
ALT TEXT (teks alternatif gambar): untuk screen reader + Google Image Search.
  [BURUK] <img src="logo-ukmi.png" alt="image1.jpg">
  [BAIK]  <img src="logo-ukmi.png" alt="Logo UKMI Politeknik Negeri Medan">

ANCHOR TEXT (teks tautan):
  [BURUK] <a href="blog.php">klik di sini</a>
  [BAIK]  <a href="blog.php">baca panduan pendaftaran UKMI Polmed</a>

Aturan anchor text: deskriptif, mengandung keyword natural, bervariasi.

Status web ini:
  [BAIK]  Logo & gambar utama sudah punya alt deskriptif (index.php, blog.php).
  [PERLU] Pastikan SEMUA gambar (termasuk .uploads) punya alt bermakna.

--------------------------------------------------------------------------------
3.9 Konsep Tambahan (Referensi)
--------------------------------------------------------------------------------
- Core Web Vitals: LCP (<2.5s), CLS (<0.1), INP (<200ms) — sinyal Page
  Experience. Diperbaiki via optimasi gambar, dimensi eksplisit, JS ringan.
- Mobile-First Indexing: Google mengindeks versi MOBILE. Viewport, font, touch
  target (>=48px), dan konten harus setara di mobile.
- Canonical Tag: <link rel="canonical"> menentukan URL utama, cegah duplikat.
- Hreflang: menandai versi bahasa/wilayah (id, x-default) untuk i18n.
- Crawl Budget & Index Coverage: jaga situs ramping; hindari thin content,
  duplikat, dan URL sampah agar crawl budget tidak terbuang.
- Internal Linking & Link Equity: distribusi "nilai" link; anchor deskriptif.
- Search Intent: all]<｜｜begin▁of▁sentence｜｜>## all align konten dengan maksud
  pencarian (informational, navigational, transactional).
- Keyword Cannibalization: hindari banyak halaman menarget keyword sama.
- Snippet & Meta: title 50-60 char, description 150-160 char, unik per halaman.
- Image SEO: WebP/AVIF, srcset responsif, loading="lazy" untuk bawah fold,
  width/height eksplisit, nama file deskriptif,compression.
- Structured Data Testing: Rich Results Test, Schema Validator.
- Log File Analysis & Crawl Stats: pahami perilaku Googlebot.
- SERP Features: featured snippet, People Also Ask, video/FAQ rich result.
- YMYL (Your Money Your Life): standar E-E-A-T lebih ketat utk topik sensitif.

BAGIAN 9 — TEMUAN: TEMBOK PROTEKSI ANTI-BOT INFINITYFREE
================================================================================

Tanggal dicatat : 2026-11-16
Konteks        : Fitur social sharing (Open Graph) blog tidak menampilkan
                 thumbnail di WhatsApp — hanya tampil domain "ukmipolmed.my.id"
                 tanpa judul/gambar.

--- 9.1 Gejala ---
Share URL postingan (https://ukmipolmed.my.id/blog/<slug>) ke WhatsApp / X /
Telegram / LinkedIn menampilkan preview kosong (tanpa og:title, deskripsi,
maupun thumbnail). Facebook & Google normal.

--- 9.2 Akar masalah ---
InfinityFree menyuntikkan CHALLENGE JavaScript ("aes.js" + cookie "__test")
sebelum PHP berjalan. Challenge ini KURANG LEBIH berbasis User-Agent:
crawler yang TIDAK menjalankan JavaScript menerima halaman challenge HTML
(bukan konten asli), sehingga tidak ada meta OG dan tidak ada gambar.

--- 9.3 Bukti uji (fetch server dengan berbagai UA) ---
  LOLOS (konten asli):
    - Googlebot
    - Bingbot
    - Yandex
    - facebookexternalhit (Facebook/WhatsApp parser versi FB)
  KENA CHALLENGE (menerima halaman aes.js):
    - WhatsApp
    - Twitterbot / X
    - TelegramBot
    - LinkedInBot
    - Applebot (preview iMessage)
    - Slackbot
    - Discordbot
    - Bravebot / Brave Search (crawler)  [diuji 2026-11-17]
    - Browser biasa via curl / curl-default

Kode OG sendiri SUDAH BENAR (diverifikasi):
  - HTML postingan memuat og:title, og:description, og:type=article, og:url,
    og:image = https://ukmipolmed.my.id/og-image.php?slug=<slug>,
    og:image:type=image/jpeg, twitter:image.
  - og-image.php mengembalikan HTTP 200, Content-Type image/jpeg,
    501.788 byte, JPEG valid 1400x1254 (disajikan langsung dari base64,
    tanpa folder .uploads/).

--- 9.4 Kesimpulan ---
Ini BUKAN bug kode/.htaccess. Challenge disuntikkan di lapisan server
(hosting) sebelum PHP berjalan, jadi tidak dapat diperbaiki dari file proyek.
SEO Google/Bing aman (di-whitelist). Preview sosial (WhatsApp dkk) terblokir
selama anti-bot InfinityFree aktif.

--- 9.5 Opsi perbaikan (belum dieksekusi; pekerjaan dihentikan di sini) ---
  1. Matikan proteksi anti-bot di panel InfinityFree (bila tersedia).
  2. Pindah hosting tanpa JS challenge (GitHub Pages statis / Netlify /
     Vercel / hosting berbayar).
  3. Cloudflare di depan + Transform Rule ubah User-Agent ke crawler yang
     di-whitelist + Cache Rule (hack/spoofing UA, tidak dijamin, perlu akses
     nameserver domain).

permintaan pada 2026-11-16.
